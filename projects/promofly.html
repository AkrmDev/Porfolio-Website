What it is

Promofly is meant to replace hopping between six social apps. The goal is a single dashboard where you write once, schedule ahead, and publish to multiple networks — with captions that fit each platform and a simple view of what’s already posted.

Where it stands

Core pieces are in place: a React front end, Firebase for accounts and storage, and server integrations for publishing. Scheduling, multi-platform posting, captions, and analytics are being built and refined — this is a work-in-progress product, not a finished launch with published usage stats.
