Banana Kidz

A public website for Banana Kidz — a real toy store in Milan, Michigan, run by kids for kids — so visitors can learn about the shop, see what’s for sale, and know when and where to visit.

Visit site

Overview

Banana Kidz needed a friendly marketing site that matches the store’s personality. I designed and built it in Webflow so the owners can keep pages updated without writing code.

What visitors can do on the site

  • See that the store is open (or when it opens) and what the brand stands for
  • Learn how kids help run the shop and pick up real business skills
  • Browse toys, games, and gift ideas the store wants to highlight
  • Get the address, weekly hours, and phone number so they can visit in person

Deliverables

  • Responsive page layouts that work on phones and desktops
  • Easy-to-edit content sections for hours, visit info, and store story
  • Live site on Webflow at banana-kidz.com
