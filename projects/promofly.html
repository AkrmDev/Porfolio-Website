PROMOFLY

A full-stack platform that lets users manage multiple social media accounts from a single app — one app, all socials.

  • React
  • Firebase
  • Node.js
  • Express
  • Twitter API

Challenge

Creators and small teams juggle multiple social accounts with fragmented tools for login, scheduling, and posting. The goal was one coherent web app that handles auth and publishing without leaving the product.

Solution

Built a React frontend for authentication and navigation, wired Firebase for secure user management and storage, and connected the Twitter API so users can post tweets directly from the platform.
